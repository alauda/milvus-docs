# Lifecycle Policy

## Version Lifecycle Timeline

Below is the lifecycle schedule for released versions of the Alauda Data Services Vector Database E1:

| Alauda Data Services Vector Database E1 Version | Release Date | End of Support |
|:--------------------:|:------------:|:--------------------:|
| v1.3.x               | 2026-10-01   | Supported until 2028-04-01 (18 months from v1.3.10-acp.2 GA on 2026-10-01) |

## Release Policy

The Alauda Data Services Vector Database E1 follows this lifecycle:

- **Support window**: each minor version (for example, v1.3.x) receives Full Support followed by Maintenance for **18 months from its general availability (GA) date**. Patch releases within a minor version do not extend its support window. For v1.3.x, the window is counted from the v1.3.10-acp.2 GA on 2026-10-01.
- **Patch releases**: security (CVE) and bug fixes are rolled up into patch releases. Critical fixes are released on an expedited schedule.
- **Long-life releases**: minor versions designated as long-life receive backported security (CVE) and urgent bug fixes for up to **36 months** from GA, without requiring an upgrade. v1.3.x is not currently designated as a long-life release.
- **Update delivery**: updates are delivered through Alauda Cloud (AC) channels and are applied automatically or after approval by a cluster administrator.

The `chart-milvus-operator` cluster plugin is a separate product line and is not covered by this table. To move from it to this operator, see [Migrating from the chart plugin](upgrade.mdx#migrate-from-chart-plugin).

## Maintenance Policy

Alauda provides maintenance support for the Alauda Data Services Vector Database E1 based on the lifecycle described above.

During the support period of each version, Alauda provides the following services:

- **Security Updates**: Regular patches and updates in line with Alauda security standards.
- **Bug Fixes**: Timely fixes for critical and major issues, aligned with upstream Milvus and Milvus Operator community fixes.
- **Upgrade Assistance**: Guidance and support for smooth upgrades between Alauda Data Services Vector Database E1 versions.
- **Regular Maintenance**: Periodic updates to ensure the operator remains stable and compatible with the Kubernetes ecosystem.
